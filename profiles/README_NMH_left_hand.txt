NO MORE HEROES - LEFT-HAND PROFILES FOR COMBO REMAPPER 9.0
===========================================================
Made for Dani. One hand, left side of the keyboard only. No controller.


HOW TO USE
----------
1. Copy the .ini files into the "profiles" folder next to Combo_ReMapper_9_0.ahk
2. Start Combo_ReMapper_9_0.ahk
3. Pick the profile for your game from the profile menu:
     nmh1_left_hand   = No More Heroes 1
     nmh2_left_hand   = No More Heroes 2
     nmh3_left_hand   = No More Heroes 3
4. Start the game. The keys below only work while the game window is active.

The "Target program" in each profile is a guess:
     No More Heroes.exe / No More Heroes 2.exe / NMH3.exe
If the keys do nothing, check the real .exe name in Task Manager and
type it into the Target program box in the remapper.


"TOGGLE" MEANS: press once to START, press again to STOP.


F2 ........ MASTER ON/OFF. Pauses everything and lets go of held keys.
            If anything goes wrong, press F2.


NO MORE HEROES 1 and 2
----------------------
F ......... Auto-walk (holds W for you). Press again to stop.
G ......... Lock-on (holds Left Shift for you). Press again to let go.
X ......... Camera reset (taps Left Alt).
4 ......... Emergency evade (presses Shift + Space together for you).
T ......... Recharge the beam katana: holds Left Ctrl and wiggles the
            mouse by itself. Toggle.
5 ......... Recharge using the mouse wheel instead (holds Left Ctrl).
            Use this one if T does not work. Toggle.
1 ......... Auto-mash E (high slash / mash prompts). Toggle.
2 ......... Auto-click (left mouse button, fast). Toggle.
3 ......... Lawn-mowing helper: walks and turns on its own. Toggle.


NO MORE HEROES 3
----------------
F ......... Auto-walk (holds W). Toggle.
G ......... Lock-on (holds Left Shift). Toggle.
X ......... Camera reset (taps Left Alt).
6 ......... Emergency evade (Shift + Space together).
T ......... Recharge with the mouse wheel (holds Q). Toggle.
5 ......... Recharge by wiggling the mouse (holds Q). Toggle.
1 ......... Death Glove skill 1 (Q + left mouse button)
2 ......... Death Glove skill 2 (Q + right mouse button)
3 ......... Death Glove skill 3 (Q + middle mouse button)
4 ......... Death Glove skill 4 (Q + Space)
F3 ........ Auto-mash E. Toggle.
F4 ........ Auto-click. Toggle.
F5 ........ Lawn-mowing helper. Toggle.
F9 ........ Plunger helper (taps W and S quickly). Toggle.


KEYS THE GAME ALREADY USES (NMH 1 keyboard list)
------------------------------------------------
These are NOT used as triggers, so they still work normally:
   W A S D ........ move
   Arrow keys ..... camera
   Enter .......... accept
   Backspace ...... cancel / skip scene
   Tab ............ menu
   E, Q, V, C ..... high slash, low slash, high beat, low beat
   R .............. switch target
   B .............. call bike
   M .............. minimap
   7 .............. dark side
   Left Shift ..... lock-on (G does it for you)
   Left Ctrl ...... battery charge (T does it for you)
   Left Alt ....... camera reset (X does it for you)
   Space .......... emergency evade with Shift


OTHER KEYS IN THE REMAPPER ITSELF
---------------------------------
F6 ......... Y-axis lock (default, can be changed in Settings)
F7 ......... Show/hide the on-screen status box (default)

CHANGING A KEY
--------------
Open the remapper window. The left column is the key you press,
the right column is what the game receives. Click the left box and
press a new key, then save.
